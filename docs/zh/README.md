# 从一条消息开始排查

入口不变：AstrBot WebUI → 插件 → MsgDebugger → Pages → **logs**。

## 推荐阅读顺序

1. 在左侧展开一个**群聊或私聊对象**，选中一次消息记录。平台实例不同的同号群不会混在一起。每组列表分页；没有归属信息的旧记录按原会话单独显示。
2. 先看**过程总览**。这里概括原始输入、模型请求次数、工具执行和有改动的插件，再按时间顺序分开显示“准备、模型请求、工具执行、代理输出、发送前处理、发送通知”。子代理运行期间也可能出现发送前处理钩子，它不代表整条对话已经结束；发送通知也不代表对方已收到消息。展开其中一段才会出现详细日志。
3. 点**① 看模型收到什么**。切换请求时从第一条消息开始；消息目录连续滚动，内容区一次阅读一条消息。可按角色筛选、搜索内容，或用“从最后一条 user 开始”快速定位。搜索支持按钮、回车和清空。
4. 如果模型调用了多次，点顶部流程里的**请求 2**等按钮。输入页会说明和前次请求有多少条相同的前缀；“定位本次新增 / 变化处”会跳到第一个不同位置。该位置可能是修改或新增，不代表之前所有内容都没变。
5. 看见可疑内容后，去**插件改动**找修改来源，或用**请求对比**查看完整差异。顶部流程可定位对应阶段；阶段内的“查看插件改动”可定位相关插件。模型输入、工具目录、技能目录和请求对比共用选中的模型请求；工具执行、插件改动和用量展示整条记录。

## 第一次接触 LLM API

输入页的“如何读这份请求快照”解释消息顺序、工具目录、工具执行循环，以及 AstrBot 的额外内容字段。角色解释放在具体消息旁边。

**50 条输入消息不等于调用模型 50 次。** 一次请求会携带一个有顺序的 `messages` 列表，历史问题与历史回复也可能在里面。请求中的 `assistant` 是带入的上下文；本次生成的输出在输入列表之外单独查看。`user` 可能混有 AstrBot 或插件附加的材料，不一定等于用户原话。

每条消息都有角色解释、在列表中的前后位置和原始内容。`#50` 只表示它是列表的第 50 项。可以从最后一条 `user` 开始读，再按需看全局指令、先前上下文、工具调用和结果。

## 导航变化与布局

- 原模型输入的长卡片列表 → 连续消息目录 + 单条内容阅读器。
- 原总览的逐阶段长日志 → 流程分段，详细日志默认折叠。
- 原左侧平铺记录 → 按平台实例、群聊 / 私聊对象分组。
- 八个标签和 `logs` 入口保留；新增贯穿标签的执行流程导航。
- “Skills”标签 → “技能”；“Agent 输出” → “代理输出”；“发送完成” → “发送通知”。用量中的“服务商回报总计” → “API 返回用量（累计）”，统计口径不变。
- 缩小标题区、卡片间距和工具栏；宽屏的会话列表与内容区分别滚动，窄屏自动上下排列。
- 对话记录和请求对比的翻页按钮位于各自列表上方。比较对象超过一页时，列表使用紧凑滚动区域，长消息页与末页保持相同高度；只有一页时自然展开。

自动刷新只更新左侧列表；详情使用“更新这条记录”，保留已有展开项和阅读位置。切换标签也会记住阅读位置，切换请求则从头阅读。新增归属字段需要重载插件后采集新消息；缺少信息的旧记录不会被猜测性归类。

采集能力、存储限制、可选插件接入见 [项目说明](../../README.md)。

## 采集状态与变化内容

工具记录同时覆盖主代理的 AstrBot 工具事件和使用默认 Agent 钩子的嵌套 `tool_loop_agent`。嵌套工具会标记 `agent_scope: nested`。AstrBot 的工具异常路径不会调用结束钩子，调试器会从实际写回模型的 `error:` 工具结果补记“子代理工具失败”。使用自定义 Agent 钩子或第三方 Runner 的工具仍可能只能从模型请求中看到，页面不会据此假定工具已执行。

工具页将一次调用的开始与返回合并为一张卡片；同一范围内的同名工具按采集顺序配对，并发时不能保证一一对应。“未采集到返回”可能表示仍在运行、记录被截断，或执行路径没有结束事件。总览保留事件顺序，“开始调用”表示已记录开始事件，不代表工具当前仍在运行。

技能开关与所属插件状态分开显示。插件停用或未注册时，即使技能开关仍开启，该插件技能也会被 AstrBot 请求筛选器排除；最终以选中请求携带的目录为准。

插件改动中的红色删除 / 绿色新增差异默认折叠，仅保留少量上下文；原始修改前后快照仍可展开。差异太长会标注截断，旧记录重新打开后也可查看。

技能页通过“查看”切换选中请求包含的技能目录与本地文件、开关及所属插件状态。人格或配置可能进一步筛选技能；目录进入请求不代表模型读取或执行了技能。本地目录可手动刷新。自定义提示词格式和截断快照无法保证识别。

新记录支持 AstrBot Pydantic v1 消息组件。旧记录中的 unavailable 表示当时采集器未能记录组件，无法恢复已缺失字段。响应返回后的 GeneratorExit 不再当成调用失败；完整响应前关闭或取消记为请求中断。旧版响应后的同类误报保留原文并作说明。
